``` r
library(ggplot2)
data("penguins", package = "palmerpenguins")
```

The penguins table contains 344 observations and 8 variables. Each
observation represents one penguin. Measurements include bill length,
bill depth, and flipper length in millimeters, as well as body mass in
grams.

Firstly, for the “species” variable, there are three different species,
which are Adelie, Gentoo, Chinstrap. Secondly, “island” variable depicts
three islands penguins inhabit, which are Torgersen, Biscoe, Dream.

The mean of flipper length is 200.92 mm, excluding missing values.

``` r
penguin_plot =  ggplot( data = penguins, mapping = aes(y = flipper_length_mm, x = bill_length_mm, color = species)) + geom_point()
```
