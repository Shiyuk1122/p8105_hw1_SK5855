``` r
set.seed(42)
example_df = tibble(
  samp = rnorm(10),
  positive = samp > 0,
  text_label = c("a", "b" , "c" , "d", "e", "f", "g", "h", "i", "j"),
    factor_label = factor(
    c("low", "high", "medium", "low", "low", "high", "low", "high", "medium", "low"),
```

When calculating these 4 types of variables, we found that numeric and
logical variable have the ouput of mean. For numeric, the mean is
0.5472968, it doesn’t equal to 0 because it’s generate based on 10
random observations. For logical, True = 1 and False = 0, so the mean
will be a number within 0 and 1, which represents the proportion of True
results.

For factor and character, return value is NA since mean() function
cannot calculate directly under these 2 variables.

``` r
as.numeric(pull(example_df, positive))
as.numeric(pull(example_df, text_label))
as.numeric(pull(example_df, factor_label))
```

We can know from the numeric switch that numeric, logical and factor
variable can be expressed in numeric form. Logical has two values: 0
and 1. Factor label has three values: 1, 2, 3, corresponding to three
different categories: low, medium and high. Although their mean can be
calculated after conversion, it would be an average of category codes
rather than a meaningful measurement. The character variable in this
example contains letters, so as.numeric() produces NA values with a
warning. Character strings representing numbers, such as “10”, can
instead be converted successfully.
